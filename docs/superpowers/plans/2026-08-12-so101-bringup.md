# SO-101 Bring-up Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Mac-ready LeRobot SO-101 project with conda install plus numbered scripts that safely bring up 12V STS3215 leader and follower arms through find-port → motor IDs → calibrate → teleop.

**Architecture:** Shell wrappers around official Hugging Face LeRobot CLI (`lerobot-find-port`, `lerobot-setup-motors`, `lerobot-calibrate`, `lerobot-teleoperate`). Shared `_common.sh` loads `config/ports.env`, validates distinct ports, activates the `lerobot` conda env, and prints leader/follower power banners. LeRobot itself is cloned into `third_party/lerobot` and installed editable with `[feetech]`.

**Tech Stack:** macOS zsh/bash, Miniconda/conda, Python 3.12, Hugging Face `lerobot` v0.6.1 + Feetech/hardware extras, Feetech STS3215 @ 12V, Waveshare-style MotorsBus boards

## Global Constraints

- Host: macOS only for this project
- Servos: STS3215 **12V** on both leader and follower — always use **12V** PSUs
- Scope: bring-up only (no cameras, record, train, eval)
- Arm separation: follower scripts must never configure leader hardware and vice versa
- Calibration ids: follower `my_follower_arm`, leader `my_leader_arm`
- Robot/teleop types: `so101_follower` / `so101_leader`
- Project root: `/Users/romil/Developer/Lerobot setup`
- Spec: `docs/superpowers/specs/2026-08-12-so101-bringup-design.md`

```bash
#!/usr/bin/env bash
# Shared helpers for SO-101 bring-up scripts. Source me; do not execute.

project_root() {
  local here
  here="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
  printf '%s' "$here"
}

banner_follower_only() {
  cat <<'EOF'
============================================================
 FOLLOWER ONLY
 - Power ON:  FOLLOWER bus + 12V PSU + USB
 - Power OFF: LEADER bus (unplug USB and/or 12V)
============================================================
EOF
}

banner_leader_only() {
  cat <<'EOF'
============================================================
 LEADER ONLY
 - Power ON:  LEADER bus + 12V PSU + USB
 - Power OFF: FOLLOWER bus (unplug USB and/or 12V)
============================================================
EOF
}

banner_both_arms() {
  cat <<'EOF'
============================================================
 BOTH ARMS (teleop)
 - Power ON: FOLLOWER bus + 12V + USB
 - Power ON: LEADER bus + 12V + USB
============================================================
EOF
}

load_ports() {
  local root ports
  root="$(project_root)"
  ports="${PORTS_FILE:-$root/config/ports.env}"
  if [[ ! -f "$ports" ]]; then
    echo "Missing $ports — run scripts/01_find_port.sh first (or copy ports.env.example)." >&2
    return 1
  fi
  # shellcheck disable=SC1090
  set -a
  source "$ports"
  set +a
  FOLLOWER_ID="${FOLLOWER_ID:-my_follower_arm}"
  LEADER_ID="${LEADER_ID:-my_leader_arm}"
  if [[ -z "${FOLLOWER_PORT:-}" || -z "${LEADER_PORT:-}" ]]; then
    echo "FOLLOWER_PORT and LEADER_PORT must both be set in $ports" >&2
    return 1
  fi
  if [[ "$FOLLOWER_PORT" == CHANGE_ME* || "$LEADER_PORT" == CHANGE_ME* ]]; then
    echo "Replace CHANGE_ME_* placeholders in $ports" >&2
    return 1
  fi
  if [[ "$FOLLOWER_PORT" == "$LEADER_PORT" ]]; then
    echo "FOLLOWER_PORT and LEADER_PORT must be different devices (got $FOLLOWER_PORT)" >&2
    return 1
  fi
  return 0
}

require_conda_lerobot() {
  if ! command -v conda >/dev/null 2>&1; then
    echo "conda not found. Install Miniconda, then re-run env/setup_env.sh" >&2
    return 1
  fi
  # shellcheck disable=SC1091
  eval "$(conda shell.bash hook)"
  conda activate lerobot
  if ! command -v lerobot-calibrate >/dev/null 2>&1 && ! python -c "import lerobot" >/dev/null 2>&1; then
    echo "lerobot not installed in conda env 'lerobot'. Run bash env/setup_env.sh" >&2
    return 1
  fi
  return 0
}

confirm_continue() {
  read -r -p "Confirm hardware matches the banner above, then press Enter (Ctrl-C to abort) "
}
```

```bash
#!/usr/bin/env bash
set -euo pipefail

ROOT="$(cd "$(dirname "$0")/.." && pwd)"
LEROBOT_DIR="$ROOT/third_party/lerobot"
REPO_URL="https://github.com/huggingface/lerobot.git"

if ! command -v conda >/dev/null 2>&1; then
  echo "Install Miniconda first: https://docs.conda.io/en/latest/miniconda.html" >&2
  exit 1
fi

# shellcheck disable=SC1091
eval "$(conda shell.bash hook)"

if conda env list | awk '{print $1}' | grep -qx lerobot; then
  echo "Conda env 'lerobot' already exists — reusing."
else
  conda create -y -n lerobot python=3.10
fi
conda activate lerobot

mkdir -p "$ROOT/third_party"
if [[ ! -d "$LEROBOT_DIR/.git" ]]; then
  git clone "$REPO_URL" "$LEROBOT_DIR"
else
  echo "Found existing clone at $LEROBOT_DIR"
fi

cd "$LEROBOT_DIR"
pip install -e ".[feetech]"

echo
echo "Setup complete. Next:"
echo "  conda activate lerobot"
echo "  bash scripts/01_find_port.sh"
```

### Task 4: Port discovery script

**Files:**
- Create: `scripts/01_find_port.sh`

**Interfaces:**
- Consumes: `lerobot-find-port` CLI; user plugs one bus at a time
- Produces: `config/ports.env` with distinct `FOLLOWER_PORT` / `LEADER_PORT` and default ids

- [ ] **Step 1: Write `scripts/01_find_port.sh`**

```bash
#!/usr/bin/env bash
set -euo pipefail
ROOT="$(cd "$(dirname "$0")/.." && pwd)"
# shellcheck source=scripts/_common.sh
source "$ROOT/scripts/_common.sh"
require_conda_lerobot

PORTS_OUT="$ROOT/config/ports.env"

echo "=== Discover FOLLOWER port ==="
banner_follower_only
confirm_continue
echo "Running lerobot-find-port — disconnect FOLLOWER when prompted."
FOLLOWER_PORT="$(lerobot-find-port | tee /dev/stderr | awk '/The port of this MotorsBus is/{print $NF}')"
if [[ -z "$FOLLOWER_PORT" ]]; then
  read -r -p "Paste FOLLOWER port path (e.g. /dev/tty.usbmodem...): " FOLLOWER_PORT
fi

echo
echo "=== Discover LEADER port ==="
banner_leader_only
confirm_continue
echo "Running lerobot-find-port — disconnect LEADER when prompted."
LEADER_PORT="$(lerobot-find-port | tee /dev/stderr | awk '/The port of this MotorsBus is/{print $NF}')"
if [[ -z "$LEADER_PORT" ]]; then
  read -r -p "Paste LEADER port path (e.g. /dev/tty.usbmodem...): " LEADER_PORT
fi

if [[ "$FOLLOWER_PORT" == "$LEADER_PORT" ]]; then
  echo "Ports must differ. Got follower=$FOLLOWER_PORT leader=$LEADER_PORT" >&2
  exit 1
fi

cat > "$PORTS_OUT" <<EOF
FOLLOWER_PORT=$FOLLOWER_PORT
LEADER_PORT=$LEADER_PORT
FOLLOWER_ID=my_follower_arm
LEADER_ID=my_leader_arm
EOF

echo
echo "Wrote $PORTS_OUT"
cat "$PORTS_OUT"
echo "Next: bash scripts/02_setup_motors_follower.sh (FOLLOWER only powered)"
```
